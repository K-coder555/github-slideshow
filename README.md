# GitHub Learning Lab Repository for Introducing GitHub

Welcome to your repository for the GitHub Learning Lab course. This repository is designed to guide you through various activities to help you learn and master GitHub. 

## 주요 기능

- GitHub Learning Lab bot을 통해 Git 및 GitHub 학습
- reveal.js를 사용한 슬라이드 쇼 기능
- 이슈 및 풀 리퀘스트를 통한 상호작용 학습

## 설치 및 실행 방법

1. 이 저장소를 클론합니다.

    ```bash
    git clone https://github.com/your-username/github-learning-lab.git
    ```

2. 프로젝트 디렉토리로 이동합니다.

    ```bash
    cd github-learning-lab
    ```

3. 필요한 패키지를 설치합니다.

    ```bash
    npm install
    ```

4. 슬라이드 쇼를 시작합니다.

    ```bash
    npm start
    ```

## 환경 변수/설정

- `_config.yml` 파일에서 슬라이드 쇼의 다양한 설정을 조정할 수 있습니다.
- `timezone`, `highlighter`, `markdown` 등의 설정을 필요에 따라 변경할 수 있습니다.

## 사용 예시

슬라이드 쇼를 시작하면 오른쪽 화살표 키를 사용하여 슬라이드를 탐색할 수 있습니다.

```markdown
---
layout: slide
title: "Welcome to our slide deck!"
---

Use the right arrow to begin!
```
