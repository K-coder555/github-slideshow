# GitHub Learning Lab Repository for Introducing GitHub

Welcome to your repository for the GitHub Learning Lab course. This repository is designed to guide you through various activities to help you learn and master GitHub. 

## 프로젝트 소개

GitHub Learning Lab을 통해 Git과 GitHub의 다양한 주제를 배우고 익히기 위한 재미있는 활동을 제공합니다. 

## 주요 기능

- GitHub Learning Lab bot을 통한 학습 지원
- reveal.js를 사용한 슬라이드 쇼 기능
- Git 및 GitHub 학습을 위한 실습 활동 제공

## 설치 및 실행 방법

1. 이 저장소를 클론합니다.

    ```bash
    git clone <repository-url>
    ```

2. 필요한 패키지를 설치합니다.

    ```bash
    npm install
    ```

3. 슬라이드 쇼를 시작합니다.

    ```bash
    npm start
    ```

## 환경 변수/설정

- `_config.yml` 파일에서 슬라이드 쇼의 다양한 설정을 조정할 수 있습니다.
- 타임존 설정: `timezone: Europe/Berlin`
- 마크다운 파서 설정: `markdown: kramdown`

## 예시 코드 또는 사용 예시

슬라이드 쇼를 시작하려면 오른쪽 화살표 키를 사용하세요.

```markdown
---
layout: slide
title: "Welcome to our slide deck!"
---

Use the right arrow to begin!
```
